# Notepad

Create or update a short project notepad the user can @-mention later.

1. Ask the topic (phase notes, decisions, open questions)
2. Write a markdown file under `.cursor/notepads/` (create folder if needed), e.g. `.cursor/notepads/phase-2-empathize.md`
3. Keep it short: goals, decisions, open questions, links to files
4. Do not put secrets or API keys in notepads
5. Tell the user they can reference it with `@` in chat
